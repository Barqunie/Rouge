model adiyla tutuldu; Betisa adina otomatik karakter eslestirmesi yapilmadi.

Unreal: PNG'leri UI texture olarak import edebilirsin. Texture Group: UI,
Compression: UserInterface2D (RGBA), Mip Gen: NoMipmaps, sRGB acik.
UMG Image / karakter Blueprint DisplayInfo Portrait alaninda kullanilabilir.
Bu teslim gorsel dosyalaridir; lobby widget/Blueprint'leri degistirilmedi.

Gorseller yerlesik image_gen ile ayri ayri uretildi. Tam kullanilan promptlar
ve kaynak dosya adlari generation_prompts.json dosyasindadir. Uretilen alfa
kanali ve dosyalar degistirilmeden korunmustur.
